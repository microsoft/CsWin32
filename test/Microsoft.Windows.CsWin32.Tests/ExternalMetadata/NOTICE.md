This folder contains winmd files we use for testing. Some come from external sources, and some are small authored fixtures kept in source form in this repository.

Metadata | Source
--|--
ServiceFabric.winmd | [youyuanwu/fabric-metadata](https://github.com/youyuanwu/fabric-metadata/raw/a1bcca6ad6f6a772c9e5ff4bdba80ae5e5f24cfc/.windows/winmd/ServiceFabric.winmd)
CustomIInspectable.winmd | Generated using WinMDGenerator toolchain. Project in the subdirectory [CustomIInspectable](../../CustomIInspectable) with build instructions in [readme.md](../../CustomIInspectable/readme.md).
WnfWithoutStatusSuccess.winmd | Authored fixture for issue #1677 regression coverage. Its source is checked in as [WnfWithoutStatusSuccess.il](WnfWithoutStatusSuccess.il). We keep this one as IL because that is much easier to maintain than reproducing the full end-to-end WinmdGenerator workflow for a focused test asset.
SelfContained.winmd | Authored fixture reproducing the OSClient single-`Generator` build configuration (a non-`Windows.Win32` metadata assembly with the Windows.Win32 projection provided by a reference), where special string typedefs (`PCWSTR`) must be referenced under `Windows.Win32.Foundation`. Its source is checked in as [SelfContained.il](SelfContained.il). Kept as IL for the same reason as WnfWithoutStatusSuccess.winmd.
SafeHandleOwnership.winmd | Authored fixture for contextual `RAIIFree` and `FreeWith` ownership, HANDLE input inference without type-level ownership, exact native value types, caller-defined cleanup, and cleanup functions that return `BOOLEAN`. Its source is checked in as [SafeHandleOwnership.il](SafeHandleOwnership.il), including the IL assembler command. Tests load this asset rather than emitting metadata at runtime.
FlatNamespace.winmd | Authored fixture for issue #1848 regression coverage, with native typedefs and associated enums at the common namespace root and in a nested namespace. Its source and regeneration command are checked in as [FlatNamespace.il](FlatNamespace.il).
TypeDefConstant.winmd | Authored fixture verifying that struct-typed constants defined in the same metadata module using TypeDefinition handles (rather than TypeReference handles) correctly nest into the struct and attach to extension blocks. Its source is checked in as [TypeDefConstant.il](TypeDefConstant.il). Kept as IL for the same reason as WnfWithoutStatusSuccess.winmd.
Windows.SdkBaseline.winmd | Complete Windows metadata generated from public Windows SDK CPP 10.0.28000.2705 headers with D3D12 definitions emitted into a separate provider. Pinned public source, emitter and regeneration commands are documented in [AgilitySdk](../../AgilitySdk/README.md).
Microsoft.Direct3D.D3D12.Baseline.winmd | The matching complete Windows SDK D3D12 provider, emitted from the same source compilation as Windows.SdkBaseline.winmd. The file name differs from its stable assembly identity so tests can select it separately from Agility.
Microsoft.Direct3D.D3D12.winmd | Alternative provider generated from released Microsoft.Direct3D.D3D12 1.619.3 headers and existing public WinSDK manual constants, referencing only the split Windows contract. No private SDK payloads. See [AgilitySdk](../../AgilitySdk/README.md) for provenance and regeneration.
