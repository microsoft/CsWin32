# Public Windows and Agility SDK test metadata

Tests select a split Windows contract and exactly one D3D12 provider. The
Windows file contains no D3D12 definitions; its references explicitly name the
provider assembly. Both baseline and Agility providers have the same unsigned
`Microsoft.Direct3D.D3D12.winmd` identity and version **1.0.0.0**. Package
versions are independent of this metadata identity.

The complete Windows baseline pair comes from public Windows SDK CPP
**10.0.28000.2705** headers, without Agility header substitution. It was emitted
from the public source generated by
[win32metadata CI run 41341276440](https://github.com/microsoft/win32metadata/actions/runs/41341276440),
using the namespace-routing implementation preserved in public
[`microsoft/win32metadata` commit 4688aedce13bee8167fbf387e9927741872ebbb2](https://github.com/microsoft/win32metadata/tree/4688aedce13bee8167fbf387e9927741872ebbb2).
The full files preserve the semantic closure and architecture variants; they
are not pruned or authored stand-ins.

`AgilitySdk.proj` generates the alternative provider from `d3d12.h` in released
**Microsoft.Direct3D.D3D12 1.619.3**, using public Windows CPP
**10.0.26100.7705** headers. It also includes the existing public WinSDK manual
D3D12 constants, including `D3D12_DEFAULT_SHADER_4_COMPONENT_MAPPING`, which
the header scraper cannot evaluate as a function-like macro. The emitter
references only the split Windows contract. No private Agility headers or SDK
723 payloads are included.

## Regeneration

In a separate checkout of the immutable win32metadata commit above, follow its
build prerequisites and run:

```powershell
$env:NBGV_GitEngine = 'Disabled'
dotnet build BuildTools -c Release
. .\scripts\CommonUtils.ps1
Install-VsDevShell
dotnet build generation\WinSDK -c Release -t:EmitWinmd
```

This emits `bin\Windows.Win32.winmd` and `bin\Microsoft.Direct3D.D3D12.winmd`
from one source compilation. Copy them to this repository's
`test\Microsoft.Windows.CsWin32.Tests\ExternalMetadata` as
`Windows.SdkBaseline.winmd` and `Microsoft.Direct3D.D3D12.Baseline.winmd`.
Renaming the files does not change their assembly identities.

Then, from the CsWin32 repository, generate the public Agility provider:

```powershell
$env:NBGV_GitEngine = 'Disabled'
dotnet restore test\AgilitySdk\AgilitySdk.proj
dotnet msbuild test\AgilitySdk\AgilitySdk.proj -t:Build `
  -p:Win32MetadataSourceRoot=<absolute-path-to-that-win32metadata-checkout> `
  -p:CorrectedEmitterToolsDir=<that-checkout>\bin\Release\net10.0 `
  -p:SplitWindowsMetadataDir=<that-checkout>\bin
```

The output is
`test\Microsoft.Windows.CsWin32.Tests\ExternalMetadata\Microsoft.Direct3D.D3D12.winmd`.
These are generated public-header test fixtures, not official SDK packages.
CI consumes the checked-in files without running the scraper.
